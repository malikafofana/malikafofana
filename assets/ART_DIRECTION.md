# Portfolio identity

The profile and portfolio share a navy background (#10132a), electric blue (#4d7aff), crimson (#ff4a60), white (#f7f8fb) and muted text (#aab0c4).

The animated header uses the same brain artwork and moving neural connections as the portfolio, with Malika's Allura signature. English copy presents AI and data engineering alongside software development. The contribution calendar continues to display real GitHub activity.

The header animation is a 4.8 second loop. Its text remains readable throughout.
